As operações realizadas no banco de dados utilizam Prepared Statements para evitar a montagem de comandos SQL diretamente com os dados informados pelo usuário.
Também foram utilizadas validações para verificar os dados antes de serem enviados para o banco.
Organização
Os arquivos PHP foram separados de acordo com suas funções, facilitando a organização e manutenção do projeto.
O sistema possui uma interface simples para que seja possível cadastrar, visualizar, editar e excluir os brinquedos.
Objetivo
O objetivo deste projeto foi praticar os conceitos de CRUD, PHP, MySQL, Prepared Statements, validação de dados e tratamento básico de erros.
